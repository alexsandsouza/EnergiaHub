# Laboratório 2.0 Alpha

Simulador local de dois sensores adimensionais com funções periódicas determinísticas, amostragem nominal de 1 segundo e janela de 60 pontos. Não é um modelo físico validado nem um gêmeo digital de instalação real. Não há MQTT, hardware, API ou telemetria real. Testes de navegador pendentes. Frontend estável permanece identificado como v1.8; módulo experimental separado.
